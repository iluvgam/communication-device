# Friends Chat 0.2 test

Download FriendsChat-0.2-Windows-x64.zip, extract it, and open FriendsChat.exe. Replace the old version on both laptops.

New: Find local chats, one-click invitation copying, invitation import, adapter names beside host IPs, connection checks, and clearer error messages. The host's own messages stay inside the host process; laptop-to-laptop connections still require TLS and verified certificate fingerprints.

Host: select Wi-Fi, Host Chat, Copy invitation. Send it privately to your friend through a trusted channel. Friend: paste, Use invitation, confirm the source, Join Chat.

Discovery is optional and unverified. It cannot bypass firewall/hotspot filtering. Norton certificate replacement is rejected; an authorized administrator may need to review compatibility. Seven focused local tests passed; full TLS retesting was blocked by Norton interception, and two-laptop testing remains necessary. Read TESTING.md included in the download.
